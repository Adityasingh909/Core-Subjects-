# Practice Problems

Try these without looking up a solution first. Create one `.java` file per problem and keep the public class name identical to the filename.

## Beginner

1. Create a `Book` class with title, author, and price fields. Add a method to display its details.
2. Create a `Rectangle` class with constructors and methods for area and perimeter.
3. Create a `Student` class that stores marks for three subjects and calculates the average.
4. Create a `BankAccount` class with deposit and withdraw methods. Reject invalid amounts.
5. Create a `Car` class and two objects with different values.

## Intermediate

6. Create `Animal`, `Dog`, and `Cat` classes to demonstrate inheritance.
7. Demonstrate method overloading with a `Calculator`.
8. Demonstrate method overriding using `Shape`, `Circle`, and `Rectangle`.
9. Create an abstract `Employee` class with subclasses for full-time and part-time employees.
10. Create an interface `Playable` implemented by `Guitar` and `Piano`.
11. Create a custom exception for an invalid age.
12. Use `static` to count how many objects of a class have been created.

## Revision questions

- What is the difference between a class and an object?
- Why should fields often be `private`?
- What is the difference between overloading and overriding?
- Can an abstract class be instantiated?
- How can a Java class implement multiple interfaces?
- What is the difference between `this` and `super`?
- What is the difference between `throw` and `throws`?
